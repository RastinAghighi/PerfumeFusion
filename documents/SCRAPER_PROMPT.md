# Fragrantica Perfume Scraper — Claude Code Prompt

## Goal
Build a Python web scraper that extracts perfume data from Fragrantica.com and saves it to a single `data/perfumes.json` file. This data will later be used as game content for a perfume merge/fusion game.

## Tech Stack
- Python 3
- Playwright (NOT requests/BeautifulSoup — Fragrantica is JavaScript-rendered and has bot protection)
- JSON for output

## Setup
- Windows PowerShell environment
- Use `py` instead of `python`, and `py -m pip` instead of `pip`
- Install Playwright: `py -m pip install playwright` then `py -m playwright install chromium`

## What to Scrape
For each perfume, extract:
- `name` (string) — perfume name
- `brand` (string) — designer/brand name
- `rating` (float) — average rating out of 5
- `votes` (int) — number of votes/ratings
- `gender` (string) — "men", "women", or "unisex"
- `notes_top` (list of strings) — top notes
- `notes_middle` (list of strings) — middle/heart notes
- `notes_base` (list of strings) — base notes
- `image_url` (string) — URL of the perfume bottle image
- `url` (string) — Fragrantica page URL for reference

## Scraping Strategy
1. Start from Fragrantica's search or browse pages (e.g., https://www.fragrantica.com/search/)
2. Fragrantica limits search results to ~1000 per query, so scrape by category/year/brand to get broader coverage
3. For the game, we need at least 500-1000 perfumes across a range of ratings (1.0 to 5.0)
4. Visit each perfume's individual page to get the full details (notes, rating, votes)

## Anti-Bot Measures
- Add random delays between requests (3-8 seconds)
- Use a realistic user-agent string
- Run Playwright in headed mode first for testing, headless for production
- If Fragrantica shows a CAPTCHA or blocks, pause and retry after a longer delay
- Save progress incrementally — write to JSON after every 50 perfumes so we don't lose data if it crashes

## Output Format
Save to `data/perfumes.json`:
```json
[
  {
    "name": "Sauvage",
    "brand": "Dior",
    "rating": 4.21,
    "votes": 28450,
    "gender": "men",
    "notes_top": ["pepper", "bergamot"],
    "notes_middle": ["lavender", "geranium"],
    "notes_base": ["ambroxan", "cedar", "labdanum"],
    "image_url": "https://...",
    "url": "https://www.fragrantica.com/perfume/Dior/Sauvage-31861.html"
  }
]
```


## Important Notes
- Save progress incrementally. If the script crashes at perfume 300, I don't want to re-scrape 1-299.
- Log progress to console: "Scraped 50/1000... Scraped 100/1000..." etc.
- If a perfume page fails to load, skip it and log the URL to a `data/failed_urls.txt` file for retry later.
- Keep it simple. No database, no API, no server. Just scrape and save to JSON.
